Field Twin Violet

Field Twin Violet is a parts inventory app for field crews. It is part of the Field Twin family.

It is built around parts. Home has quick actions, and each item has a page with photos, vendors, and reorder levels. An order list tracks what to buy, orders can be read from a photo, and arrivals check off open orders. Items can be moved between locations, including storage units. Uploads wait on the phone when something is missing, so records are not lost. It shares one sign in with the other Field Twin apps.

Live at field-twin-violet.vercel.app
